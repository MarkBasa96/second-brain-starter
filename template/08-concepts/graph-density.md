# Graph density

Links per note. The single variable that decides whether a knowledge graph looks alive or like scattered dust.

No styling substitutes for it. Colour, forces and glow only make sparse data prettier. Density comes from [[atomic-notes]] plus disciplined wikilinking.

Unresolved links count: writing `[[something-unwritten]]` puts a dim ghost note on the map immediately and marks work worth doing.

Part of [[second-brain]].
