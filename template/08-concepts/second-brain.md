# The second brain

A folder of plain markdown notes that you and an AI both read and write. It remembers what you decided, what went wrong, and what you are aiming at, so every new session starts informed instead of blank.

Four ideas make it work: [[two-layers]] (strategy above, execution below), [[memory-in-the-vault]] (memory is files, not hidden settings), [[atomic-notes]] (one idea per note, so the graph is a web) and [[autonomy]] (the AI earns more freedom as trust grows).

Everything is reachable from [[00-concept-map]]. The AI's name and the owner's name live in the root CLAUDE.md, written by the brain-setup skill.
