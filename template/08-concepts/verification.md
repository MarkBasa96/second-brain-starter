# Verification

Run the cheapest experiment that would prove a claim before declaring it.

Four shapes of claim need it: *impossible* ("can't be done"), *sufficient* ("good enough"), *categorical* ("your account is the kind that...") and *verified* ("that worked"). A returned success is not proof of an effect.

Design the test so it can fail; a test everything passes has measured nothing. Related: [[clarifying-questions]], and the mistakes log in [[memory-in-the-vault]].
