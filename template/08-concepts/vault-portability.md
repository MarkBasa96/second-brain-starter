# Vault portability

Memory, skills and agent definitions live in the vault as markdown, so the brain survives changing tools, computers or AI models.

If a skill only exists inside one app's private config, switching apps loses it. If it is a file in your vault, you copy the folder and you are done. This is the reason [[memory-in-the-vault]] is a folder and not a setting.
