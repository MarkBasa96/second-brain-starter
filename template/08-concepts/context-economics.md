# Context economics

Everything in the root CLAUDE.md loads on every single turn. A skill's body loads only when invoked; only its name and description are always present.

So situational detail belongs in a skill, not in the root file. Trimming CLAUDE.md saves tokens on every exchange. It is also why [[delegation]] is not free and why [[roster-cap]] is a number.

Part of [[second-brain]].
