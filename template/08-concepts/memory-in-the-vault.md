# Memory in the vault

Memory is plain markdown files in `07-memory/`, indexed by `MEMORY.md`, not something hidden inside one tool's settings.

Two payoffs. Any AI tool that can read files sees the same memory ([[vault-portability]]). And you can open, correct or delete a memory yourself.

Mistakes get their own log (`feedback_mistakes_log.md`): what happened, the root cause, the rule that prevents it. Writing it down is what stops it happening twice. See [[verification]].

Part of [[second-brain]].
