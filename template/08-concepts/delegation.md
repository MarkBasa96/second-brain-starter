# Delegation

Handing a whole task to a helper agent instead of doing it in the main thread. Buys a clean context and a specialist; costs tokens, because each helper starts fresh ([[context-economics]]).

Works only when routing is unambiguous, which is why [[roster-cap]] exists. Distinct from [[agent-teams]], where agents coordinate with each other.

Part of [[second-brain]].
