# Skill: wrap-up

A long session's decisions otherwise live only in a chat that is about to close.
Do these, in order, and keep it fast.

1. **Journal.** Append a section to `02-journals/<today>.md` (create it if missing)
   with: *Shipped*, *Decided*, *Learned*, *Not done / unverified*. Plain language,
   dates absolute. Link every project and concept you touched.
2. **Mistakes.** Anything that went wrong or cost time goes into
   `07-memory/feedback_mistakes_log.md` as one dated entry: what happened, the root
   cause, the rule that prevents it.
3. **Memory.** If the owner told you a standing preference today, save it as a file in
   `07-memory/` and add one line to `07-memory/MEMORY.md`.
4. **Projects.** Update each touched project's `CLAUDE.md` "Next step".
5. **Open loops.** Append anything still owed to `00-goals/open-loops.md` as a
   checklist, one line each, with who owes it.
6. **Say it back.** Give the owner a five-line summary and name the first thing to
   do next session.

Never write passwords, ID numbers or bank details into any of these.
