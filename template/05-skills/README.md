# Skills

A skill is a small instruction file the AI loads only when needed. The working
copies live in `.claude/skills/<name>/SKILL.md`. This folder is for notes about them.

Starter skills: **brain-setup** (one-time interview), **new-project**, **weekly-update**,
**wrap-up**. Why skills and not a bigger CLAUDE.md: [[context-economics]].
Related: [[second-brain]].
